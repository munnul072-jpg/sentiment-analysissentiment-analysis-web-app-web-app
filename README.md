# Sentiment Analysis Web Application

A Flask-based web application that performs sentiment analysis on text data using Machine Learning and Natural Language Processing (NLP) techniques.

---

## 🚀 Features
- Predicts sentiment (Positive, Negative, Neutral)
- Uses TF-IDF vectorization and ML models
- Real-time prediction using Flask web interface
- Handles user input dynamically

---

## 🛠️ Tech Stack
- Python
- Flask
- Scikit-learn
- NLTK
- HTML/CSS

---

## 📊 Project Overview
This project analyzes user input text and predicts sentiment using trained machine learning models. It uses NLP techniques for preprocessing and classification.
